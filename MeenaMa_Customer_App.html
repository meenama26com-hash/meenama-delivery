↩️ 72-Hour Return Policy

Return your delivered order within 72 hours

You may request a return within 72 hours from the time your order is marked as Delivered.
  • Return requests are accepted only within the 72-hour return window.
  • The product should be unused and kept in its original condition, packaging, tags and accessories where applicable.
  • Please provide a clear return reason and description when submitting the request.
  • Return approval is subject to verification by MeenaMa Delivery.
  • After the 72-hour window closes, the return option will no longer be available in the app.
Common return reasons: Wrong item, damaged item, missing item, incorrect size/variant, quality issue, or other genuine issue.
